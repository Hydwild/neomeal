# NeoMeal — память проекта

Обновлено: 2026-10-16

## О проекте
Android-трекер питания NeoMeal (папка «NutriTrack 113»): Kotlin, XML Views,
Room (схема v20) + SQLCipher. Публикуется в RuStore, репозиторий
github.com/Hydwild/neomeal.
Сборка: `$env:JAVA_HOME = "$env:ProgramFiles\Android\Android Studio\jbr"`, затем
`.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest`; для проверки R8 —
`:app:assembleRelease`.
