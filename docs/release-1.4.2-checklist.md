## 2. Подпись APK (делает владелец ключа)

Подпись автоматическая: как только в **корне репозитория** появится
`keystore.properties`, `assembleRelease` подпишет APK сам
(см. `app/build.gradle`, строки 9–15 и 30–49).

Формат `keystore.properties` (файл вне git, в `.gitignore`):

```properties
storeFile=C:/путь/к/neomeal-release.jks
storePassword=<пароль хранилища>
keyAlias=<алиас ключа>
keyPassword=<пароль ключа>
```

> ВАЖНО: ключ должен быть **тем же самым**, что у 1.3.2 / 1.4.0 / 1.4.1.
> Другой ключ = RuStore отклонит обновление (несовпадение подписи).

Сборка:

```powershell
$env:JAVA_HOME = "$env:ProgramFiles\Android\Android Studio\jbr"
.\gradlew.bat clean :app:assembleRelease
```

Результат: `app/build/outputs/apk/release/app-release.apk`
(без keystore получается `app-release-unsigned.apk` — такой в магазин не годится).
